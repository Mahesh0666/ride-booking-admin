# RideAdmin - Admin Dashboard

Admin panel for managing ride booking operations with 2FA login and email OTP.

## Quick Start

```bash
# Backend
cd backend
npm install
npm start

# Admin Dashboard
cd admin-dashboard
npm install
npm run dev
```

Open http://localhost:5173
